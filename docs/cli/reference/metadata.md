# Metadata

Command reference for `fargo metadata`, generated from the CLI's help output.

```text
Description:
  List the numeric codes and names the API uses for its enumerations.

Usage:
  fargo metadata [command] [options]

Options:
  --username <username>  Username to authenticate with for this invocation. Provide together with --password to sign in just for this command.
  --password <password>  Password to authenticate with for this invocation. Provide together with --username to sign in just for this command.
  -?, -h, --help         Show help and usage information
  --server <server>      The Fargo server URL to connect to (e.g. https://localhost:7563). Overrides the configured server for this invocation.
  -v, --verbose          Show detailed diagnostics for errors, including exception types, inner exceptions, and stack traces.

Commands:
  entity-types            List the entity types.
  
                          Examples:
                            fargo metadata entity-types
  audit-log-types         List the audit log types.
  
                          Examples:
                            fargo metadata audit-log-types
  action-types            List the action (permission) types.
  
                          Examples:

  actor-types             List the actor types.
  
                          Examples:
                            fargo metadata actor-types
  article-types           List the article types.
```
