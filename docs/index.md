# Fargo

Fargo is an inventory management system: a catalog of articles, the items that
exist of them and where they are, all scoped by partitions that decide who can
see what. It is used through a REST API, a command-line client, an MCP server
for AI agents, and real-time push.

> [!NOTE]
> Fargo is under active development and is not yet production-ready.
